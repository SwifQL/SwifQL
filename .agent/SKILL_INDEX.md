# Skill Index

Skills are reusable operational procedures, not architecture authority. Architecture rules remain in `.agent/architecture/**` and are routed by `ARCH_INDEX.md`.

Load at most one skill by default, and only when the task matches its procedure.

- `skills/adding_new_builder.md` — adding or extending a builder.
- `skills/adding_new_sql_function.md` — adding a compositional SQL function helper.
- `skills/extending_dialect.md` — adding or changing a SQL dialect, including future dialect research and implementation.

Create a new skill only after repeated work demonstrates a stable, reusable procedure that does not belong in an architecture owner.
